Automation & risk limits

Change only while stopped
Micro cycles · PAPER only

Used only when the strategy is Micro. The budget is the most an entry may take from simulated cash, including the fee reserve; it is never raised automatically, and a pair whose exchange minimum needs more is shown as ineligible with the smallest budget that would work. Micro mode is PAPER only and refuses live trading.

Hard limits (per-order and per-asset USDT caps, order rate, daily realised-loss stop and drawdown stop) are enforced by an independent risk gate on every order path, including the manual ticket; the kill switch blocks new orders instantly and a latched stop needs the phrase RESUME TRADING to clear. Long-only, no leverage, no shorting. Entry checks require trend, 20-bar breakout, RSI, volume, volatility, higher-timeframe alignment and spread/liquidity constraints. Market filters also require a directional 20-candle move and, for altcoins, a BTC uptrend on the confirmation timeframe; they only skip entries and never change stops or exits. Rapid mode still uses completed candles; shorter intervals increase API load and trading costs. Exit checks run only while the bot is running.

Enable real-money trading?

Connecting MEXC or Kraken API credentials can allow this program to place real spot market orders with your balance. Meme coins can move sharply, orders can slip, and software stops will not work if the PC, network or exchange is offline.

  • Only exchange API keys with account-read and spot-trading privileges may be used. Withdrawal permission must remain disabled.
  • Verify that this exchange legally serves your location. MEXC identifies the UK among its restricted jurisdictions.
  • Use small amounts and review live order activity directly on the exchange.
